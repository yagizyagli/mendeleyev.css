# 🧪 Mendeleev.css v1.0.0

A modern CSS library that brings the **Periodic Table of Elements** into web development. Inspired by the fact that HTML has `color: tomato` but lacks fundamental elements like `titanium`, `uranium`, or `platinum`.

---

## 🚀 How to Use (Nasıl Kullanılır?)

You can easily use this library in your web projects by following the methods below:

### Method 1: Direct CDN Link (En Hızlı Yöntem)
Add this line inside the `<head>` tag of your HTML file:
```html
<link rel="stylesheet" href="https://jsdelivr.net">
```

### Method 2: Manual Download (Manuel Yükleme)
1. Download the `mendeleev.css` file from this repository.
2. Link it to your HTML project:
```html
<link rel="stylesheet" href="path/to/mendeleev.css">
```

---

## 🎨 Code Examples (Kod Örnekleri)

Once included, you can use the predefined utility classes anywhere in your HTML:

### 1. Radioactive Glowing Elements (Parlayan Radyoaktif Efektler)
```html
<!-- Glows in neon green -->
<h1 class="mndlv-uranium">Hazardous Content</h1>

<!-- Glows in neon red/orange -->
<p class="mndlv-neon">Live Server Active</p>
```

### 2. Realistic Metallic Gradients (Metalik Arka Planlar)
```html
<!-- Beautiful chrome gradient -->
<div class="mndlv-bg-chrome">Premium Plan</div>

<!-- Elegant copper gradient -->
<button class="mndlv-bg-copper">Buy Now</button>
```

## 🧪 Available Elements (Kütüphanedeki Elementler)

- **Radioactive:** `.mndlv-uranium`, `.mndlv-plutonium`, `.mndlv-radium`, `.mndlv-thorium`
- **Noble Gases:** `.mndlv-neon`, `.mndlv-helium`, `.mndlv-argon`, `.mndlv-krypton`, `.mndlv-xenon`
- **Metallic Gradients:** `.mndlv-bg-titanium`, `.mndlv-bg-platinum`, `.mndlv-bg-chrome`, `.mndlv-bg-copper`, `.mndlv-bg-iron`, `.mndlv-bg-mercury`, `.mndlv-bg-bismuth`
- **Non-Metals:** `.mndlv-sulfur`, `.mndlv-carbon`, `.mndlv-chlorine`
